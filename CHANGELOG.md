# Список изменений

## [Qt 6] — 2026-09-23

Проект переведён с Qt 5.11.3 на Qt 6.11.1. Исправлены ошибки, из-за которых программа падала, выдавала неверные сообщения или раздавала устаревшее обновление.

### Переход на Qt 6.11.1

- Сборка под Qt 6.11.1 (MinGW 64-bit), стандарт C++17.
- `QZipReader` подключается через `QT += core-private`. Жёсткие пути к `C:\Qt\Qt5.11.3` из `untitled.pro` убраны: проект собирается на любом компьютере с Qt 6.11.1.
- Удалённая в Qt 6 функция `QDateTime::fromTime_t` больше не используется.
- Удалены сгенерированные файлы Qt 5 (`Makefile*`, `ui_*.h`, `.qmake.stash`, `object_script.*`). Добавлен `.gitignore`.
- В репозиторий добавлена папка `source/` с картинками: без неё проект не собирался.
- Картинки с кириллицей в имени переименованы: `герб1.png` → `gerb1.png`, `герб2.png` → `gerb2.png`, `МПИ.tif` → `mpi.tif`. `mingw32-make` не находил файлы с такими именами.

### Исправлено: падения программы

- **Выход из программы.** Раньше программа падала при закрытии, если в этом сеансе ничего не загружали: удалялся неинициализированный указатель.
- **Потоки распаковки.** Каждая загрузка оставляла незавершённый поток, и при выходе это приводило к падению. Теперь поток завершается после распаковки, а при закрытии программа дожидается его окончания.
- **Журнал загрузок.** Открытие журнала при пустой истории больше не роняет программу.
- **Выбор пути сохранения.** Нажатие «Отмена» в окне выбора папки больше не роняет программу.
- **Список подразделений.** Если `data_list.json` нельзя прочитать или создать, используется встроенный список. Раньше программа уходила в бесконечную рекурсию.

### Исправлено: неверное поведение

- **Замена архива обновления.** Раньше новый архив не заменял старый: копирование молча не срабатывало, а дата на экране при этом обновлялась. Пользователи получали устаревшую базу. Теперь архив действительно заменяется, а при ошибке появляется сообщение.
- **Сообщения о результате распаковки.** Если архив не удалось прочитать, раньше показывалось «Обновление успешно загружено». Теперь выводится сообщение с причиной ошибки.
- **Кнопка «Загрузить».** Больше не блокируется навсегда при ошибке распаковки.
- **Проверка записи.** Каждый файл проверяется на успешную запись. Вложенные папки из архива создаются автоматически.
- **Журнал загрузок:**
  - запись появляется только после успешной загрузки, а не до неё;
  - дни отсортированы по дате, свежие сверху (раньше сортировка шла как по строкам: `01.10` оказывалось раньше `02.09`).
- **Путь сохранения.** Сохраняется выбранная папка целиком, а не только буква диска.
- **Дата на главном экране.** Обновляется сразу после загрузки нового архива.
- **Размер архива:**
  - на файлах больше 2 ГБ значение больше не переполняется;
  - размер показывается с одним знаком после запятой, архив меньше 1 МБ больше не отображается как «0 MB».
- **Скрытое админ-меню.** Таймер скрытия меню срабатывал каждые 2 минуты бесконечно и сбивал набор секретной комбинации. Теперь он срабатывает один раз.
- **Выбор подразделения:**
  - выделение сбрасывается корректно (`clearSelection()`);
  - таймер сброса запускается и при выборе с клавиатуры.
- **Файл истории.** Исправлена ошибка со скобкой в проверке открытия `history_dowload.json`: программа пыталась писать в файл, даже если он не открылся.

### Безопасность

- Пути вида `../` внутри zip-архива отклоняются: архив не может записать файлы за пределы папки `Обновление Dr.Web`.
- При неверном графическом пароле окно сразу закрывается с сообщением «Неверный пароль». Раньше нужно было «дощёлкать» до 9 нажатий, и ничего не объяснялось. Сами узоры не изменились.

### Прочее

- Удалён неиспользуемый код: `getDir`, `mkDirs`, поле `_thread`.
- Устранены утечки памяти (`QSettings`, `QThread`, `ThreadZip`).
- Убраны лишние вызовы `show()` перед `exec()` у диалогов.
- Проверка пароля переписана без копипасты.
